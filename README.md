# agu-quant

A股短线研究与量化实验工具（教育用途）

范围
- 搭建数据、因子、信号、回测、候选池的研究流水线
- 提供可运行策略与展示报告的 Web UI（FastAPI + React）
- 不输出具体荐股，最终交易决策由你自行判断

当前状态
- 已完成项目骨架，下一步是接入数据源与首个信号模型

快速开始（计划）
- Python 3.10+
- 创建虚拟环境
- 安装依赖（待定）
- 配置数据源 Token（如需要）
- 运行每日流水线生成候选池报告

安全与合规
- 仅用于研究与学习
- 不构成投资建议
- 不提供自动交易指令

目录结构
- `src/agu_quant`: 核心库（数据、因子、信号、回测、报告）
- `apps/api`: 后端 API（计划）
- `apps/web`: 前端 Web（计划）
- `docs`: 研究笔记与系统设计
- `scripts`: 命令行与工具脚本

数据源规划
- 原型阶段：AkShare（免费）
- 规模化阶段：Tushare Pro / JQData / RQData（按缺口升级）

交易与账户
- 先接入模拟盘
- 后续接入平安证券实盘（需券商提供接口或文档）
