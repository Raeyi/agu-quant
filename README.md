# agu-quant

A股短线研究与量化实验工具

## 定位与原则

- 面向 A 股低价小盘短线策略的研究、回测与候选池输出
- 不输出具体荐股，最终交易决策由你自行判断
- 不提供自动交易指令

## 系统总架构

- 数据源与采集：AkShare（原型）、Tushare Pro / JQData / RQData（规模化）
- 数据层：统一字段、复权、交易日对齐、增量更新、质量校验
- 指标与因子：情绪、题材、资金、技术、筹码
- 信号与评分：规则化信号、组合评分、候选池生成
- 回测与评估：日频与隔夜、交易成本、风控与统计
- 报告与可视化：候选池报告、回测报告、复盘摘要
- 服务化与前端：FastAPI + React
- 账户与交易：先模拟盘，后续对接券商实盘（如可用接口）

## 短线策略要素到模块映射

- 市场情绪监控：涨跌停统计、封板率、连板晋级率、炸板率
- 题材强度与轮动：板块涨幅、涨停家数、主线题材识别
- 资金流动追踪：龙虎榜、换手率、封单强度、大单净流
- 技术与筹码结构：关键形态、均线结构、筹码分布
- 选股流程与交易管理：竞价筛选、打分体系、止盈止损与仓位管理

## 开发路线（建议）

- 阶段 0：统一数据层与字段规范，保证可复用的数据基建
- 阶段 1：情绪与题材模块落地，形成每日情绪与题材面板
- 阶段 2：资金与技术模块落地，形成可解释的信号集合
- 阶段 3：候选池打分与回测闭环，完善风控与统计
- 阶段 4：API 与前端落地，形成可视化与稳定输出

## 数据假设与限制

- A 股 T+1 交易规则导致当日信号无法当日卖出
- 涨跌停制度对流动性与回测收益有影响，需显式建模
- 资金流向与龙虎榜存在时效与可得性差异，需先做日频版本

## 数据源与覆盖范围（预算友好）

- 免费优先：日线 OHLCV、基础行情、基础行业/概念分类
- 付费优先：资金流向、龙虎榜明细、逐笔/大单、新闻舆情
- 设计原则：缺失数据不阻断流程，模块可选、评分自动降级

## 目录结构

- `src/agu_quant`: 核心库（数据、因子、信号、回测、报告）
- `apps/api`: 后端 API（计划）
- `apps/web`: 前端 Web（计划）
- `docs`: 研究笔记与系统设计
- `scripts`: 命令行与工具脚本

## 安全与合规

- 仅用于研究与学习
- 不构成投资建议
